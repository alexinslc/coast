# Coast 0.1.0

Coast's first public release brings smooth, adjustable scrolling to conventional mouse wheels on macOS while leaving trackpads, Magic Mouse input, and other continuous scrolling unchanged.

## Highlights

- Smooth cubic ease-out animation for discrete vertical and horizontal wheel ticks.
- Adjustable scroll distance, animation duration, and vertical/horizontal direction.
- Immediate direction reversal, Shift-to-horizontal scrolling, and independent motion on both axes.
- Native menu-bar experience with a guided welcome flow, clear Accessibility status, and Open at Login support.
- Local-only preferences with no analytics, networking, updater, helper process, or third-party dependencies.
- Universal app for Apple Silicon and Intel Macs running macOS 13 Ventura or later.

## Install

1. Download `Coast-0.1.0-macOS.zip` and expand it.
2. Move `Coast.app` to `/Applications`.
3. Open Coast and complete its welcome flow.
4. Grant Coast Accessibility access when macOS asks. Coast needs this permission only to replace discrete wheel events with smooth scrolling.

The app is signed with Developer ID and notarized by Apple. macOS may still display its normal first-launch confirmation for software downloaded outside the Mac App Store.

The SHA-256 checksum is published beside the release asset so the downloaded ZIP can be verified before installation.

## Known limitation

Coast classifies scrolling from event metadata rather than hardware identity. Mouse software that already emits continuous pixel-based events is passed through unchanged and may not receive additional smoothing.
